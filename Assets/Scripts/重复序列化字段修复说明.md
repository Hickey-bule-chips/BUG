# 重复序列化字段修复说明

## 问题描述
Unity报错：`The same field name is serialized multiple times in the class or its parent class. This is not supported: Base(HiddenBookEnemy) spriteRenderer`

## 问题原因
这个错误发生是因为：
1. `BookEnemy` 基类中有 `spriteRenderer` 字段
2. `HiddenBookEnemy` 子类中也在使用相同的字段名
3. Unity的序列化系统不允许父子类中有同名的序列化字段

## 解决方案

### 修复前的问题代码
```csharp
// BookEnemy.cs
protected SpriteRenderer spriteRenderer;

// HiddenBookEnemy.cs  
// 没有声明字段，但直接使用父类的spriteRenderer
// 这会导致Unity序列化冲突
```

### 修复后的代码
```csharp
// BookEnemy.cs
protected SpriteRenderer spriteRenderer;

// HiddenBookEnemy.cs
private SpriteRenderer hiddenEnemyRenderer;  // 使用不同的字段名

void Start()
{
    hiddenEnemyRenderer = GetComponent<SpriteRenderer>();
}

private void UpdateVisibility()
{
    if (hiddenEnemyRenderer == null) return;
    
    if (isPlayerVisionFixed)
    {
        hiddenEnemyRenderer.color = visibleColor;
        hiddenEnemyRenderer.enabled = true;
    }
    else
    {
        hiddenEnemyRenderer.color = hiddenColor;
    }
}
```

## 修复要点

### 1. 字段命名
- 使用 `hiddenEnemyRenderer` 而不是 `spriteRenderer`
- 避免与父类字段名冲突

### 2. 组件获取
- 在 `Start()` 方法中获取 `SpriteRenderer` 组件
- 存储在 `hiddenEnemyRenderer` 字段中

### 3. 引用更新
- 更新所有对 `spriteRenderer` 的引用为 `hiddenEnemyRenderer`
- 包括 `UpdateVisibility()` 方法中的所有引用

## 为什么这样修复

### Unity序列化规则
- Unity不允许父子类中有同名的序列化字段
- 即使字段访问级别不同，也会产生冲突
- 必须使用不同的字段名来避免这个问题

### 最佳实践
- 子类应该使用自己的字段名
- 避免直接使用父类的私有/受保护字段
- 保持代码的清晰性和可维护性

## 修复结果
- ✅ 消除了重复序列化错误
- ✅ 保持了功能完整性
- ✅ 代码更加清晰和可维护
- ✅ 符合Unity的最佳实践

## 注意事项
- 如果将来需要在其他地方使用 `spriteRenderer`，请使用 `hiddenEnemyRenderer`
- 这种修复方式确保了父子类的字段命名不会冲突
- 建议在创建继承关系时考虑字段命名的唯一性
