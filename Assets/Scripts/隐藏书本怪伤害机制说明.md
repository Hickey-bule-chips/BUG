# 隐藏书本怪伤害机制说明

## 概述
隐藏书本怪具有特殊的伤害机制：只有在修复视觉开启时，玩家的笔芯攻击才能对隐藏书本怪造成伤害。当修复视觉关闭时，隐藏书本怪对笔芯攻击免疫。

## 伤害机制规则

### 1. 普通书本怪
- **总是可以被笔芯攻击伤害**
- 不受修复视觉状态影响
- 正常的伤害计算和血量减少

### 2. 隐藏书本怪
- **只有在修复视觉开启时才能被笔芯攻击伤害**
- 修复视觉关闭时：笔芯击中隐藏书本怪不会造成伤害
- 修复视觉开启时：笔芯击中隐藏书本怪正常造成伤害

## 技术实现

### PenCoreProjectile修改
```csharp
// 检查是否是隐藏书本怪
HiddenBookEnemy hiddenBookEnemy = bookEnemy as HiddenBookEnemy;
if (hiddenBookEnemy != null)
{
    // 隐藏书本怪只有在修复视觉开启时才能被伤害
    if (playerAbilityManager != null && playerAbilityManager.IsRepairVisionActive())
    {
        bookEnemy.TakeDamage(damage);
        Debug.Log($"笔芯击中隐藏书本怪，造成 {damage} 点伤害！（修复视觉已开启）");
    }
    else
    {
        Debug.Log("笔芯击中隐藏书本怪，但修复视觉未开启，无法造成伤害！");
    }
}
else
{
    // 普通书本怪总是可以受到伤害
    bookEnemy.TakeDamage(damage);
}
```

### 关键组件依赖
1. **PlayerAbilityManager** - 提供修复视觉状态检查
2. **PenCoreProjectile** - 检查修复视觉状态决定是否造成伤害
3. **HiddenBookEnemy** - 特殊类型标识

## 游戏体验设计

### 策略性
- 玩家必须管理精神值来激活修复视觉
- 需要权衡精神值消耗与攻击隐藏书本怪的时机
- 增加了游戏的策略深度

### 挑战性
- 隐藏书本怪在隐藏时仍然可以攻击玩家
- 玩家需要主动激活修复视觉才能反击
- 创造了不对称的战斗机制

### 视觉反馈
- 修复视觉开启时：隐藏书本怪变为可见，可以受到伤害
- 修复视觉关闭时：隐藏书本怪隐藏，笔芯攻击无效
- 清晰的调试信息显示伤害是否生效

## 使用场景

### 正常战斗流程
1. 玩家遇到隐藏书本怪
2. 隐藏书本怪开始攻击玩家（接触伤害）
3. 玩家按Shift键激活修复视觉
4. 隐藏书本怪变为可见
5. 玩家用笔芯攻击隐藏书本怪
6. 隐藏书本怪受到伤害并可能死亡

### 精神值管理
1. 玩家精神值不足时无法激活修复视觉
2. 无法对隐藏书本怪造成伤害
3. 只能躲避或承受隐藏书本怪的攻击
4. 需要等待精神值恢复

## 调试信息
系统会输出详细的调试信息：
- "笔芯击中隐藏书本怪，造成 X 点伤害！（修复视觉已开启）"
- "笔芯击中隐藏书本怪，但修复视觉未开启，无法造成伤害！"

## 配置要求
1. 确保PlayerAbilityManager存在于玩家对象上
2. 确保PenCoreProjectile正确配置
3. 确保HiddenBookEnemy正确设置Tag和组件

## 扩展可能性
1. 可以添加其他类型的隐藏敌人
2. 可以调整伤害机制（如部分伤害）
3. 可以添加特殊的视觉效果
4. 可以添加音效反馈

这种伤害机制设计增加了游戏的策略性和挑战性，要求玩家在精神值管理和战斗策略之间做出权衡。
