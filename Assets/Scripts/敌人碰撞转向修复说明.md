# 敌人碰撞转向修复说明

## 问题描述
敌人接触到ObstacleWall时会卡在ObstacleWall中，而不是转向飞行。

## 问题原因分析

### 1. 方向覆盖问题
- 敌人撞到障碍物时，会反转移动方向
- 但在下一帧的UpdateMovement中，如果还在追随玩家，会重新计算朝向玩家的方向
- 这导致反转的方向被覆盖，敌人继续朝向玩家移动，从而卡在障碍物中

### 2. 碰撞检测时机问题
- 只有OnCollisionEnter2D检测碰撞，没有处理持续碰撞的情况
- 敌人可能会卡在障碍物边缘，需要持续的反转逻辑

## 解决方案

### 1. 添加碰撞冷却机制

**新增状态变量**：
```csharp
private float collisionCooldown = 0.5f; // 碰撞冷却时间
private float lastCollisionTime = 0f; // 上次碰撞时间
```

### 2. 改进移动逻辑

**碰撞冷却时间内的特殊处理**：
```csharp
private void UpdateMovement()
{
    if (rb == null) return;
    
    // 检查是否在碰撞冷却时间内
    bool isInCollisionCooldown = Time.time - lastCollisionTime < collisionCooldown;
    
    if (isFollowingPlayer && player != null && !isInCollisionCooldown)
    {
        // 正常情况下，朝向玩家移动
        Vector2 directionToPlayer = (player.position - transform.position).normalized;
        currentDirection = directionToPlayer;
        rb.velocity = directionToPlayer * enemyData.moveSpeed;
    }
    else if (isInCollisionCooldown)
    {
        // 在碰撞冷却时间内，使用当前方向移动（避免方向被覆盖）
        rb.velocity = currentDirection * enemyData.moveSpeed;
    }
    else
    {
        // 停止移动
        rb.velocity = Vector2.zero;
    }
}
```

### 3. 碰撞检测改进

**OnCollisionEnter2D - 初始碰撞处理**：
```csharp
private void OnCollisionEnter2D(Collision2D collision)
{
    if (collision.gameObject.CompareTag("Wall") || 
        collision.gameObject.CompareTag("Ground") ||
        collision.gameObject.layer == LayerMask.NameToLayer("Ground") ||
        collision.gameObject.layer == LayerMask.NameToLayer("ObstacleWall"))
    {
        // 反转移动方向
        currentDirection = -currentDirection;
        
        // 更新碰撞时间，开始碰撞冷却
        lastCollisionTime = Time.time;
        
        Debug.Log($"{enemyData.enemyName} 撞到障碍物，反转方向: {collision.gameObject.name}");
    }
}
```

**OnCollisionStay2D - 持续碰撞处理**：
```csharp
private void OnCollisionStay2D(Collision2D collision)
{
    if (collision.gameObject.CompareTag("Wall") || 
        collision.gameObject.CompareTag("Ground") ||
        collision.gameObject.layer == LayerMask.NameToLayer("Ground") ||
        collision.gameObject.layer == LayerMask.NameToLayer("ObstacleWall"))
    {
        // 如果已经过了碰撞冷却时间，再次反转方向
        if (Time.time - lastCollisionTime >= collisionCooldown)
        {
            currentDirection = -currentDirection;
            lastCollisionTime = Time.time;
            Debug.Log($"{enemyData.enemyName} 持续碰撞，再次反转方向: {collision.gameObject.name}");
        }
    }
}
```

## 修复效果

### ✅ **解决的问题**

1. **敌人不再卡在ObstacleWall中**：
   - 碰撞冷却机制防止方向被立即覆盖
   - 持续碰撞检测确保敌人能够脱离卡住状态

2. **更自然的转向行为**：
   - 敌人撞到障碍物后会保持反转方向一段时间
   - 避免了频繁的方向切换

3. **更好的碰撞处理**：
   - 同时处理初始碰撞和持续碰撞
   - 确保敌人能够从各种碰撞情况中恢复

### 🎯 **技术优势**

**碰撞冷却机制**：
- 防止方向在碰撞后立即被覆盖
- 给敌人足够时间执行转向动作
- 避免频繁的方向切换

**持续碰撞检测**：
- 处理敌人卡在障碍物边缘的情况
- 确保敌人能够脱离卡住状态
- 提供更稳定的碰撞响应

**智能移动逻辑**：
- 根据碰撞状态调整移动行为
- 在碰撞冷却时间内保持转向方向
- 正常情况下继续追随玩家

## 参数调优

### 碰撞冷却时间
- `collisionCooldown = 0.5f`：可以根据需要调整
- 太短：可能还是会被覆盖方向
- 太长：敌人转向后可能无法及时恢复追随玩家

### 建议调整
- 如果敌人转向太快：增加collisionCooldown
- 如果敌人转向太慢：减少collisionCooldown
- 可以根据敌人的移动速度来动态调整

## 注意事项

1. **碰撞检测顺序**：确保ObstacleWall层和Ground层正确设置
2. **Tag设置**：确保相关对象有正确的Tag
3. **性能考虑**：OnCollisionStay2D会每帧调用，但碰撞冷却机制减少了不必要的计算
4. **调试信息**：可以通过日志观察敌人的转向行为

这些修复确保了敌人能够正确地处理与ObstacleWall的碰撞，不再卡住，而是能够转向飞行！
