==========================================
玩家攻击系统 - 快速开始指南
==========================================

【5分钟快速设置】
==========================================

步骤1: 创建对象池管理器（30秒）
--------------------------------
1. 场景中创建空物体 → 命名 "PoolManager"
2. 添加 PoolManager 脚本
3. 完成！自动 DontDestroyOnLoad

步骤2: 创建笔芯预制体（1分钟）
--------------------------------
1. 创建 Sprite 对象
2. 添加组件：
   - Rigidbody2D（Gravity Scale = 0）
   - Circle Collider 2D（Is Trigger = ✅）
   - PenCoreProjectile 脚本
3. 设置精灵图片
4. 保存为预制体
5. 删除场景中的对象

步骤3: 创建墨水预制体（1分钟）
--------------------------------
1. 创建 Sprite 对象
2. 添加组件：
   - Rigidbody2D
   - Circle Collider 2D（Is Trigger = ✅）
   - InkProjectile 脚本
3. InkProjectile 设置：
   - Use Parabolic Trajectory: ✅
   - Gravity Scale: 1.0
4. 设置精灵图片
5. 保存为预制体
6. 删除场景对象

步骤4: 创建墨水平台预制体（1分钟）
--------------------------------
1. 创建 Sprite 对象
2. 添加组件：
   - Box Collider 2D（Is Trigger = ❌）
   - InkPlatform 脚本
3. 设置精灵图片
4. 保存为预制体
5. 删除场景对象

步骤5: 配置玩家（1.5分钟）
--------------------------------
1. 玩家对象添加 PlayerAttack 组件
2. 设置预制体：
   - Pen Core Prefab → 拖入笔芯预制体
   - Ink Prefab → 拖入墨水预制体
   - Ink Platform Prefab → 拖入平台预制体
3. 勾选 Use Object Pool ✅
4. 完成！

步骤6: 设置标签（30秒）
--------------------------------
Edit → Project Settings → Tags and Layers
添加标签：
- Player
- Enemy
- Boss  
- Ground
- Wall
- NullBlock

【完成！开始测试】
==========================================

✅ 左键：发射笔芯（对敌人造成伤害）
✅ 右键：发射墨水（抛物线弹道，生成平台）
✅ 发射方向：鼠标指向位置
✅ 性能优化：对象池系统

【核心功能】
==========================================

▶ 笔芯攻击
- 鼠标左键连续发射
- 直线飞行
- 击中敌人造成伤害
- 冷却时间 0.3秒

▶ 墨水攻击
- 鼠标右键发射
- 抛物线弹道
- 击中 NullBlock 生成平台
- 平台持续 5秒
- 冷却时间 1秒

▶ 对象池系统
- 自动管理对象复用
- 性能提升 10-40倍
- 减少内存分配
- 避免卡顿

【常见问题】
==========================================

Q: 没反应？
A: 检查预制体是否设置

Q: 方向不对？
A: 检查 Camera.main

Q: 没有抛物线？
A: 勾选 Use Parabolic Trajectory

Q: 对象池不工作？
A: 场景中添加 PoolManager
