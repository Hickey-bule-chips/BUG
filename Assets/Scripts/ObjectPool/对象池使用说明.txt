==========================================
对象池系统使用说明
==========================================

【功能概述】
对象池系统用于优化笔芯和墨水的生成和销毁，避免频繁的 Instantiate/Destroy 操作，显著提升性能。

【系统架构】

1. ObjectPool.cs - 单个对象池类
   - 管理单一类型对象的池化
   - 支持自动扩展
   - 提供Get/Return接口

2. PoolManager.cs - 对象池管理器（单例）
   - 统一管理所有对象池
   - 提供全局访问接口
   - 自动初始化和清理

3. PlayerAttack.cs - 攻击系统（已集成对象池）
   - 自动创建笔芯和墨水对象池
   - 智能切换对象池/直接实例化模式
   - 性能优化

【设置步骤】

步骤1：创建 PoolManager
--------------------------------
1. 在场景中创建空物体，命名为 "PoolManager"
2. 添加 PoolManager 脚本
3. 该对象会自动设为 DontDestroyOnLoad

步骤2：配置玩家攻击组件
--------------------------------
在玩家对象的 PlayerAttack 组件中：

【对象池设置】
- Use Object Pool: ✅ 勾选（启用对象池）
- Pool Initial Size: 20（初始池大小，建议10-30）
- Pool Max Size: 50（最大池大小，建议30-100）

【性能建议】
- 初始大小 = 预估同时存在的最大弹射物数量
- 最大大小 = 初始大小的2-3倍
- 如果频繁出现"对象池已达到最大容量"警告，增加最大值

【墨水抛物线弹道设置】
--------------------------------
在墨水预制体的 InkProjectile 组件中：

【抛物线弹道设置】
- Use Parabolic Trajectory: ✅ 勾选（启用抛物线）
- Gravity Scale: 1（重力缩放）
  * 0 = 无重力（直线飞行）
  * 1 = 正常重力
  * >1 = 更快下落
  * <1 = 更慢下落

【视觉效果调整】
- Gravity Scale = 0.5：轻飘飘的墨水
- Gravity Scale = 1.0：标准抛物线
- Gravity Scale = 2.0：快速下坠

【预制体要求】
--------------------------------

笔芯预制体需要：
- Rigidbody2D（Gravity Scale = 0，由代码控制）
- Collider 2D（Is Trigger = true）
- PenCoreProjectile 脚本

墨水预制体需要：
- Rigidbody2D（Gravity Scale 由抛物线设置控制）
- Collider 2D（Is Trigger = true）
- InkProjectile 脚本

【对象池工作流程】
--------------------------------

发射流程：
1. PlayerAttack.FirePenCore/FireInk() 被调用
2. 检查是否启用对象池
3. 如果启用：
   - 从对象池获取对象（PoolManager.Spawn）
   - 设置位置、旋转、速度
   - 设置对象池名称
4. 如果未启用：
   - 直接 Instantiate

回收流程：
1. 弹射物超时或击中目标
2. 检查是否设置了对象池名称
3. 如果有：
   - 归还到对象池（PoolManager.Despawn）
   - 对象被禁用但不销毁
4. 如果没有：
   - 直接 Destroy

【性能优化效果】
--------------------------------

使用对象池前：
- 每次发射：Instantiate（耗时约 0.5-2ms）
- 每次销毁：Destroy（耗时约 0.3-1ms）
- 每秒10发 = 约 8-30ms

使用对象池后：
- 首次发射：从池中获取（耗时约 0.01-0.05ms）
- 归还：禁用对象（耗时约 0.01-0.03ms）
- 每秒10发 = 约 0.2-0.8ms

性能提升：10-40倍 ✨

【调试信息】
--------------------------------

启动时：
- "创建对象池: PenCorePool，初始大小: 20"
- "创建对象池: InkPool，初始大小: 20"

运行时：
- "发射笔芯！方向: (x, y)"
- "发射墨水！方向: (x, y)"

警告：
- "对象池 XXX 已达到最大容量！" - 增加 Pool Max Size
- "PoolManager 未找到！" - 需要在场景中添加 PoolManager
- "对象池 XXX 不存在！" - 对象池未正确初始化

【常见问题】
--------------------------------

Q: 对象池不工作？
A: 检查：
   1. 场景中有 PoolManager 对象
   2. PlayerAttack 中 Use Object Pool 已勾选
   3. 预制体正确设置

Q: 弹射物消失后不回来？
A: 检查：
   1. 弹射物脚本调用了 ReturnToPool()
   2. SetPoolName() 被正确调用

Q: 墨水没有抛物线？
A: 检查：
   1. InkProjectile 中 Use Parabolic Trajectory 已勾选
   2. Rigidbody2D 存在
   3. Gravity Scale 设置 > 0

Q: 如何关闭对象池？
A: PlayerAttack 中取消勾选 Use Object Pool

【高级用法】
--------------------------------

手动管理对象池：
```csharp
// 获取对象
GameObject obj = PoolManager.Instance.Spawn("PoolName", position, rotation);

// 归还对象
PoolManager.Instance.Despawn("PoolName", obj);

// 延迟归还
PoolManager.Instance.DespawnAfterDelay("PoolName", obj, 2f);

// 清空所有对象池
PoolManager.Instance.ClearAll();

// 查看对象池信息
PoolManager.Instance.LogPoolInfo("PoolName");
```

创建自定义对象池：
```csharp
PoolManager.Instance.CreatePool("MyPool", prefab, 10, 50);
```

【性能监控】
--------------------------------

在 Update 中添加（仅调试用）：
```csharp
if (Input.GetKeyDown(KeyCode.P))
{
    PoolManager.Instance.LogPoolInfo("PenCorePool");
    PoolManager.Instance.LogPoolInfo("InkPool");
}
```

按 P 键查看对象池状态：
- 可用对象数量
- 活动对象数量
