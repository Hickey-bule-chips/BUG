==========================================
玩家攻击系统使用说明（已集成对象池）
==========================================

【功能概述】
- 鼠标左键：发射笔芯（可连续发射，对敌人造成伤害）
- 鼠标右键：发射墨水（单次发射，抛物线弹道，生成平台）
- 发射方向：鼠标指向位置
- 性能优化：使用对象池系统

【设置步骤】

1. 创建笔芯预制体 (PenCore Prefab)
   ① 在 Hierarchy 中创建一个新的 2D 对象（例如 Sprite）
   ② 添加组件：
      - Rigidbody2D（Gravity Scale = 0）
      - Circle Collider 2D（Is Trigger = true）
      - PenCoreProjectile 脚本
   ③ 设置合适的精灵图片
   ④ 拖到 Prefabs 文件夹中创建预制体
   ⑤ 删除场景中的对象

2. 创建墨水预制体 (Ink Prefab)
   ① 在 Hierarchy 中创建一个新的 2D 对象（例如 Sprite）
   ② 添加组件：
      - Rigidbody2D（Gravity Scale 由脚本控制）
      - Circle Collider 2D（Is Trigger = true）
      - InkProjectile 脚本
   ③ 在 InkProjectile 组件中：
      - Use Parabolic Trajectory: ✅ 勾选（启用抛物线）
      - Gravity Scale: 1.0（重力缩放）
   ④ 设置墨水精灵图片
   ⑤ 拖到 Prefabs 文件夹中创建预制体
   ⑥ 删除场景中的对象

3. 创建墨水平台预制体 (Ink Platform Prefab)
   ① 创建 2D Sprite 对象
   ② 添加组件：
      - Box Collider 2D（Is Trigger = false）
      - InkPlatform 脚本
   ③ 设置平台精灵
   ④ 保存为预制体

4. 创建对象池管理器
   ① 在场景中创建空物体，命名为 "PoolManager"
   ② 添加 PoolManager 脚本
   ③ 该对象会自动设为 DontDestroyOnLoad

5. 配置玩家攻击组件
   在玩家对象的 PlayerAttack 组件中：
   
   【笔芯攻击设置】
   - Pen Core Prefab: 拖入笔芯预制体
   - Pen Core Speed: 笔芯速度（默认 15）
   - Pen Core Cooldown: 笔芯冷却时间（默认 0.3秒）
   - Pen Core Damage: 笔芯伤害（默认 1）
   
   【墨水攻击设置】
   - Ink Prefab: 拖入墨水预制体
   - Ink Speed: 墨水速度（默认 12）
   - Ink Cooldown: 墨水冷却时间（默认 1秒）
   - Ink Platform Prefab: 拖入墨水平台预制体
   - Platform Duration: 平台存在时间（默认 5秒）
   
   【发射设置】
   - Fire Point: （可选）手动创建发射点，或留空自动创建
   - Fire Point Offset: 发射点偏移距离（默认 0.5）
   
   【对象池设置】⭐
   - Use Object Pool: ✅ 勾选（性能优化）
   - Pool Initial Size: 20（初始池大小）
   - Pool Max Size: 50（最大池大小）

6. 设置标签 (Tags)
   ① 打开 Edit -> Project Settings -> Tags and Layers
   ② 添加以下标签：
      - Player（玩家）
      - Enemy（敌人）
      - Boss（Boss）
      - Ground（地面）
      - Wall（墙壁）
      - Obstacle（障碍物）
      - NullBlock（空方块，用于墨水生成平台）

【核心脚本参数详解】
==========================================

▶ PenCoreProjectile（笔芯弹射物）
--------------------------------
【笔芯设置】
- Lifetime: 3秒（弹射物存活时间）
- Damage: 1（造成的伤害值）

【效果】
- Hit Effect Prefab: 击中特效预制体（可选）

▶ InkProjectile（墨水弹射物）
--------------------------------
【墨水设置】
- Lifetime: 3秒（弹射物存活时间）

【抛物线弹道设置】⭐
- Use Parabolic Trajectory: ✅ 勾选启用
- Gravity Scale: 1.0（重力缩放）
  * 0.5 = 轻飘飘的墨水
  * 1.0 = 标准抛物线
  * 1.5 = 快速下坠
  * 2.0 = 重力加倍

【效果】
- Splash Effect Prefab: 飞溅特效预制体（可选）

▶ InkPlatform（墨水平台）
--------------------------------
【平台设置】
- Duration: 5秒（平台存在时间）
- Fade Start Time: 1秒（销毁前多久开始闪烁警告）
- Blink Interval: 0.2秒（闪烁间隔）

【视觉效果】
- Enable Fade: ✅ 勾选启用淡出效果
- Normal Color: 白色（正常颜色）
- Warning Color: 黄色（警告颜色）

【发射逻辑详解】
==========================================

▶ 鼠标输入系统
--------------------------------
- 左键（笔芯）：Input.GetMouseButton(0)
  * 持续按住 = 连续发射
  * 冷却时间 0.3秒 = 每秒最多3.3发
  
- 右键（墨水）：Input.GetMouseButtonDown(1)
  * 单次点击 = 发射一次
  * 必须松开再按才能再次发射
  * 冷却时间 1秒

▶ 方向计算
--------------------------------
1. 获取鼠标世界坐标：
   Camera.main.ScreenToWorldPoint(Input.mousePosition)

2. 计算方向向量：
   direction = (鼠标位置 - 玩家位置).normalized

3. 计算旋转角度：
   angle = Mathf.Atan2(direction.y, direction.x) * Mathf.Rad2Deg

4. 应用到弹射物：
   - 速度：rb.velocity = direction * speed
   - 旋转：transform.rotation = Quaternion.Euler(0, 0, angle)

▶ 碰撞检测逻辑
--------------------------------
【笔芯碰撞】
- 击中敌人/Boss → 造成伤害 → 归还对象池
- 击中地面/墙壁 → 生成特效 → 归还对象池
- 忽略玩家

【墨水碰撞】
- 击中NullBlock → 销毁方块 → 生成平台 → 归还对象池
- 击中地面/墙壁 → 生成飞溅特效 → 归还对象池
- 忽略玩家

【墨水平台机制】
==========================================

▶ 平台生成
--------------------------------
1. 墨水击中 NullBlock
2. 记录方块位置
3. 销毁 NullBlock
4. 在原位置生成平台
5. 设置平台存在时间

▶ 平台倒计时
--------------------------------
- 正常状态：显示正常颜色
- 警告阶段（最后1秒）：开始闪烁黄色
- 时间到：平台消失

▶ 平台特性
--------------------------------
- 可站立：Box Collider 2D（Is Trigger = false）
- 有时限：通过 InkPlatform 脚本控制
- 视觉反馈：闪烁警告即将消失

【常见问题解答】
==========================================

Q1: 为什么鼠标点击没有反应？
A: 检查以下几点：
   ✓ PlayerController 是否添加了 PlayerAttack 组件
   ✓ 预制体是否正确设置
   ✓ 冷却时间是否结束
   ✓ 鼠标是否在游戏窗口内

Q2: 笔芯/墨水飞行方向不对？
A: 检查：
   ✓ Camera.main 是否正确获取
   ✓ 鼠标位置转换是否正确
   ✓ Z轴坐标是否设置为0

Q3: 笔芯打不到敌人？
A: 检查：
   ✓ 敌人是否有 "Enemy" 或 "Boss" 标签
   ✓ 敌人是否实现了 IEnemy 接口
   ✓ 碰撞检测设置是否正确

Q4: 墨水不能生成平台？
A: 检查：
   ✓ 方块是否有 "NullBlock" 标签或名字包含 "Null"
   ✓ InkPlatformPrefab 是否设置
   ✓ 墨水和方块的碰撞层设置

Q5: 墨水没有抛物线效果？
A: 检查：
   ✓ Use Parabolic Trajectory 是否勾选
   ✓ Gravity Scale 是否 > 0
   ✓ Rigidbody2D 是否存在

Q6: 对象池不工作？
A: 检查：
   ✓ 场景中是否有 PoolManager 对象
   ✓ Use Object Pool 是否勾选
   ✓ 预制体是否正确

Q7: 平台闪烁不明显？
A: 调整：
   ✓ Warning Color 改为更醒目的颜色（如红色）
   ✓ Blink Interval 调小（如 0.1秒）
   ✓ Fade Start Time 调大（如 2秒）

【性能优化详解】
==========================================

▶ 对象池优化效果
--------------------------------
使用前：
- 每次发射：Instantiate（0.5-2ms）
- 每次销毁：Destroy（0.3-1ms）
- 每秒10发 ≈ 8-30ms

使用后：
- 从池获取：Get（0.01-0.05ms）
- 归还到池：Return（0.01-0.03ms）
- 每秒10发 ≈ 0.2-0.8ms

性能提升：10-40倍 ⚡

▶ 优化建议
--------------------------------
1. 合理设置对象池大小
   - Initial Size = 预估同时存在的弹射物数量
   - Max Size = Initial Size × 2-3

2. 使用对象池时：
   - 勾选 Use Object Pool
   - 确保 PoolManager 在场景中

3. 不使用对象池时：
   - 取消勾选 Use Object Pool
   - 系统自动使用 Instantiate/Destroy

【注意事项】
==========================================

❗ 必须设置
- Fire Point 会自动创建在角色位置 (0.5, 0, 0)
- 弹射物必须有 Rigidbody2D 组件
- Collider 必须设置 Is Trigger = true
- 所有标签必须正确设置

❗ 图层设置
- 确保图层碰撞矩阵正确配置
- 弹射物层应该与敌人层碰撞
- 弹射物层应该与地面层碰撞
- 弹射物层不应该与玩家层碰撞

❗ 场景要求
- 场景中必须有 Camera（标签为 MainCamera）
- 场景中必须有 PoolManager（如果使用对象池）
- 玩家必须有 PlayerController 和 PlayerAttack 组件

❗ 性能考虑
- 对象池推荐在移动设备上使用
- 高频发射时必须使用对象池
- 特效也应该使用对象池优化
