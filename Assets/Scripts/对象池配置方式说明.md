# 对象池配置方式说明

## 问题描述
您遇到的警告信息表明书本怪对象池被重复创建了。这是因为有两种方式可以配置对象池，需要选择其中一种。

## 两种配置方式

### 方式1：在PoolManager的poolConfigs中配置（推荐）

**优点**：
- 在编辑器中可视化配置
- 统一管理所有对象池
- 避免重复创建
- 更清晰的配置结构

**配置步骤**：
1. 在场景中选择PoolManager对象
2. 在Inspector中找到"Pool Configs"列表
3. 添加两个配置项：
   - Pool Name: "BookEnemy", Prefab: 普通书本怪预制体
   - Pool Name: "HiddenBookEnemy", Prefab: 隐藏书本怪预制体
4. 设置Initial Size和Max Size

**BookEnemySpawner配置**：
- 不需要设置normalBookEnemyPrefab和hiddenBookEnemyPrefab
- 系统会自动检查对象池是否存在，如果存在则跳过创建

### 方式2：在BookEnemySpawner中动态创建

**优点**：
- 更灵活的动态配置
- 可以根据需要调整参数

**配置步骤**：
1. 在BookEnemySpawner中设置normalBookEnemyPrefab和hiddenBookEnemyPrefab
2. 系统会自动创建对象池（如果不存在）

## 推荐配置

**推荐使用方式1**，因为：
1. 更清晰的配置结构
2. 避免重复创建警告
3. 便于管理多个对象池
4. 符合Unity的最佳实践

## 当前修复

我已经修改了代码来处理重复创建的问题：

### PoolManager新增方法
```csharp
/// <summary>
/// 检查对象池是否存在
/// </summary>
public bool PoolExists(string poolName)
{
    return pools.ContainsKey(poolName);
}
```

### BookEnemySpawner修改
```csharp
// 检查书本怪对象池是否已存在
if (!PoolManager.Instance.PoolExists("BookEnemy") || !PoolManager.Instance.PoolExists("HiddenBookEnemy"))
{
    PoolManager.Instance.CreateBookEnemyPools(normalBookEnemyPrefab, hiddenBookEnemyPrefab);
    Debug.Log("BookEnemySpawner: 成功创建书本怪对象池");
}
else
{
    Debug.Log("BookEnemySpawner: 书本怪对象池已存在，跳过创建");
}
```

## 使用建议

1. **如果使用方式1**：
   - 在PoolManager的poolConfigs中配置对象池
   - 不需要在BookEnemySpawner中设置预制体引用
   - 系统会自动跳过重复创建

2. **如果使用方式2**：
   - 在BookEnemySpawner中设置预制体引用
   - 系统会自动创建对象池（如果不存在）
   - 现在不会再出现重复创建警告

## 注意事项

- 两种方式可以同时使用，系统会自动检查避免重复创建
- 建议统一使用一种方式以保持配置的一致性
- 对象池的名称必须匹配："BookEnemy" 和 "HiddenBookEnemy"
